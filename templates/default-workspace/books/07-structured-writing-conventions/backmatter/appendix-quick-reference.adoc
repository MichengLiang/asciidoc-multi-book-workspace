= 结构化写法速查

[cols="1,2", options="header"]
|===
|写法 |含义

|`= 书名`
|书名（Document Title）。写在文件第一行，一本书只有一个。

|`= 部名`
|一部（Part，0 级）。书名之后，用一个等号写出的标题就是一部。

|`== 章`
|一章（Chapter，1 级）。

|`=== 节`
|章里的一节（2 级）。

|`==== 小节`
|3 级。

|`===== 小节`
|4 级。

|`====== 小节`
|5 级，AsciiDoc 最深的一层。

|`parts/010-home-dishes/`
|部目录的编排号：三位定宽，默认步长 10（`010`、`020`……），末位留作插入。

|`010-braised-pork.adoc`
|章文件的编排号，规则与部目录相同。

|`[.dish]`
|role：这一节在书里是什么。

|`pass:[xref:红烧肉::火候[]]`
|限定地址：几个标题同名时，把上级标题用 `::` 接在前面，指明其中一个；网页显示《红烧肉·火候》，各级之间用间隔号。

|`[#…]`
|custom ID：标题当不了地址时（同一个上级下同名，或标题里有 `#`、`::`）给它的第二个地址。

|`[.dish, 难度=中]`
|role 加上写在 attrlist 里的字段。

|`主料:: 五花肉一斤`
|标题下第一个描述列表里的字段。值要写成句子或要挂一个块时这样写；约定声明过的字段，照声明写。

|字段文字下一行的 `+`，再接一个块
|把引文、代码块或表格挂到字段上，块属于这个字段的值。

|`pass:[xref:红烧肉[]]`
|普通引用，投影为 `aat:references`。正文提到一节时，应在外面加书名号，例如 `《pass:[xref:红烧肉[]]》`。

|`pass:[xref:炒糖色[rel=depends-on]]`
|带关系谓词的引用，投影为以谓词命名的边 `rel:depends-on`。

|`[.convention, declares=roles]`
|约定声明：标题下的描述列表是 role 的词表。`declares` 还可以取 `relations`、`values`（配 `for` 与 `field`）和 `fields`（配 `for`）。
|===

写标题层级与书的各部分时，应符合下列规定：

* 标题层级连续，不跳级；
* 附录、术语表和参考文献的标题上方写 `[appendix]`、`[glossary]`、`[bibliography]` 这样的 section style；
* 书没有分部时，附录、术语表和参考文献写成 `==`，与各章并列；
* 书有分部时，它们写成 `=`，与各部并列，附录的第一层小节写 `===`；
* 附录标题不写序号；
* 前言、致谢等前置部分放在第一部之前，有没有分部都写 `==`；
* 术语表里，词条的描述列表上方也写一个 `[glossary]`。

书有分部时，若把书后部分写成 `==`，它们会成为前一部的子节。附录的字母由 Asciidoctor 生成，字母前面的词由书头的 `:appendix-caption:` 决定。section 上的 `[glossary]` 表明这一节是术语表；描述列表上的 `[glossary]` 让 Asciidoctor 按术语表的样式排这串词条，不写就排成普通的描述列表。

写引用时，应符合下列规定：

* 同一本书里经 include 拼起来的各个文件之间，引用直接写标题；
* 几个标题同名时，引用写限定地址，例如 `pass:[xref:红烧肉::火候[]]`，不必再写显示文本；
* 引用另一本书时，在书头定义一个文档属性，存那本书的入口路径（如 `:snack-book: ../02-home-snacks/book.adoc`），引用写成 `pass:[xref:{snack-book}#糖油饼[]]`，`#` 后面写那本书里的标题。

反引号只改字体，反引号里的行内宏（如 xref）和属性引用照样会被替换。要原样展示它们，应把它们包在 `pass:[pass:[…]]` 里，外面再加反引号得到等宽字体。`= 书名`、`[.dish]` 这类块写法出现在行内时不会被当作结构，用反引号即可。

每一种写法怎样选，见《xref:结构化写法决策树[]》。
