== 名称与地址

标题是一节现在的名字。读者读到的是它，引用写的也是它，因此标题就是这一节的地址，写法见《xref:标题、寻址与引用[]》。

作者想到更准确的名字时，先改标题，再改引用。标题改好以后，按旧名字写的引用都找不到目标。它们的地址里都含着旧名字，作者在书里搜一遍旧名字，就能找到每一处引用，连同显示文本和正文里写着的旧名字，逐处改成新名字。

一样东西还有别的叫法、又值得让读者查到时，应把别的叫法写进标题下的别名字段，正文只用标题这一个名字（见《xref:一样东西一个名字[]》）。例如：

[source,asciidoc]
----
[.dish]
== 番茄炒蛋

别名:: 西红柿炒鸡蛋
----

有时要改的不只是名字，还有一节收录的范围。例如菜谱里的《凉拌与腌制》改成《凉拌菜》以后，腌制不再收在这一节：

[source,asciidoc]
----
== 凉拌菜

别名:: 凉拌与腌制（旧名，那时腌制也收在这一节）
----

这时作者除了改标题，还应重读这一节的说明、收录与不收录的内容、相关的节和已经写下的结论。对搜旧名字找到的每一处引用，作者先判断它说的是留下的凉拌，还是去掉的腌制，再决定改成《凉拌菜》，还是改指讲腌制的那一节。

改名、拆分或停用一节时，应符合下列规定：

* 不为旧标题保留一节“指路”，旧名字写进别名；
* 一节被拆开或不再使用时，删掉它，或把它改成拆出来的某一节的名字。

如果保留旧标题，旧引用仍能落到它，网页上的链接不断，作者也就不会回头看这些引用。删掉或改名以后，旧引用的链接断开，搜一遍旧名字就找到它们，作者再逐一判断每一处该改指哪一节。这一节从前的样子留在版本库的历史里。

custom ID 不替代标题，也不为旧名字保留位置。重名的标题怎样写地址、custom ID 什么时候加，见《xref:标题、寻址与引用[]》。
