== 名称与地址

标题是一节现在的名字。读者读到的是它，引用写的也是它，所以标题就是这一节的地址，写法见《xref:标题、寻址与引用[]》。

名字变得更准确时，改标题，再改引用。改完标题，工作区的检查会逐处报出还写着旧名字的引用，照着改成新名字。

一样东西还有别的叫法，又值得让读者查得到时，写进标题下的别名字段；正文只用标题这一个名字（见《xref:一样东西一个名字[]》）：

[source,asciidoc]
----
[.dish]
== 番茄炒蛋

别名:: 西红柿炒鸡蛋
----

有时要改的不只是名字，还有一节收进来的范围。菜谱里的《凉拌与腌制》改成《凉拌菜》，腌制不再收在这一节：

[source,asciidoc]
----
== 凉拌菜

别名:: 凉拌与腌制（旧名，那时腌制也收在这一节）
----

这时除了改标题，还要重读这一节的说明、收什么与不收什么、相关的节和已经写下的结论。检查报出的每一处旧引用，先判断它说的是留下的凉拌，还是去掉的腌制，再决定改成《凉拌菜》，还是改指讲腌制的那一节。

不为旧标题留一节“指路”：留了，旧引用照常找到它，检查就报不出它们。旧名字写进别名。一节被拆开或不再使用时，保留它的标题，正文写明它已不再使用、以后看哪一节。

custom ID 不替代标题，也不替旧名字留位置。它只在一节要被单独引用、又与别的标题同名时才加，见《xref:标题、寻址与引用[]》。
