== 标题的 role

role 写在标题前 attrlist 里以点号开头的位置，表明这一节在书里是什么。

[source,asciidoc]
----
[.dish]
== 红烧肉

[.technique]
== 炒糖色

[.concept]
== 鱼香
----

`.dish`、`.technique`、`.concept` 是 role，分别表明红烧肉是一道菜，炒糖色是一种技法，鱼香是一个概念（一种味型）。

[cols="1,2", options="header"]
|===
|写法 |这一节是

|`[.dish]`
|一道菜。

|`[.technique]`
|一种技法。

|`[.concept]`
|一个概念：书里反复用到的一个词及其含义。
|===

一本书需要几种 role，取决于它讲的东西分几类。一个 role 在全书里应只标一种东西，即菜都写 `.dish`，写了 `.dish` 的也都是菜。

全书的 role 应写成词表，声明在书里，写法见《xref:声明本书的约定[]》。

写了 role，查询工具就能按 role 列出全书的菜，数出有几种技法。
