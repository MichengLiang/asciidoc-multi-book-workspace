== rel 关系谓词

indexterm:[relation predicate] `rel` 是 xref 边上的关系谓词。xref 所在的标题是 source heading，xref 指向的标题是 target heading。

[source,asciidoc]
----
引用规则参见 xref:stable-heading[稳定标题]。
引用规则依赖 xref:stable-heading[稳定标题, rel=depends-on]。
----

第一行没有 `rel`，表示普通引用，投影为 `aat:references`。第二行写出 `rel=depends-on`，表示 source heading 对 target heading 有可说明的依赖关系，投影为 `rel:depends-on`。

强关系才写 `rel`。普通参见、导航和弱提及保持普通 xref。

[horizontal]
depends-on:: source heading 的判断、规则或操作需要 target heading 先成立。阅读顺序不是依赖关系；普通先读建议使用普通 xref。
illustrates:: source heading 提供 target heading 的示例。
defines:: source heading 给出 target heading 所代表对象的定义。
constrains:: source heading 对 target heading 的合法写法或范围施加约束。

关系谓词描述标题之间的边。标题自身的身份使用 role 表达。
