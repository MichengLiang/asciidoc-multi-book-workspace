== 源文本与投影

同一份源文件，读者读到的是一本书，工具读到的是一张图：标题是图上的节点，role 是节点上的值，xref 是节点之间的边。

下面是一本家常菜谱的源文本：

[source,asciidoc]
----
= 家常菜谱

[.technique]
== 炒糖色

冰糖下锅，小火炒到枣红色。

[.dish]
== 红烧肉

红烧肉的红亮来自糖色，不会《xref:炒糖色[rel=depends-on]》就做不成这道菜。

=== 火候

大火烧开，转小火炖一小时。

[.dish]
== 红烧排骨

做法同《xref:红烧肉[]》，排骨焯水的时间短一些。
----

作者用 `[.technique]` 和 `[.dish]` 表明《炒糖色》是一种技法、《红烧肉》《红烧排骨》是菜；《火候》用 `===` 写在《红烧肉》下面，是它的下级标题。做红烧肉离不开炒糖色，作者便在《红烧肉》里写 `pass:[xref:炒糖色[rel=depends-on]]`，用 `rel` 表明这层依据；《红烧排骨》只是请读者参看《红烧肉》，写普通的 `pass:[xref:红烧肉[]]` 就够了。两处引用都没有写显示文本，链接上显示的就是目标标题。

asciidoc-abundant-tree 把这份源文本投影成 RDF。下面摘出与这些写法对应的几行，`<…>` 是投影给每个标题和每条引用起的节点名：

[source,turtle]
----
<…#heading-l3-o0> a aat:Heading ;
  aat:headline "炒糖色" ;
  aat:role "technique" .

<…#heading-l8-o0> a aat:Heading ;
  aat:headline "红烧肉" ;
  aat:role "dish" ;
  aat:containsDirectly <…#heading-l13-o0> ;
  rel:depends-on <…#heading-l3-o0> .

<…#heading-l13-o0> a aat:Heading ;
  aat:headline "火候" .

<…#heading-l17-o0> a aat:Heading ;
  aat:headline "红烧排骨" ;
  aat:role "dish" ;
  aat:references <…#heading-l8-o0> .

<…#xref-edge-l11-c15-o0> a aat:XrefEdge ;
  aat:targetSelector "炒糖色" ;
  aat:targetHeading <…#heading-l3-o0> ;
  aat:rel "depends-on" .
----

每个标题的原文记在 `aat:headline`，role 记在 `aat:role`，上下级记成 `aat:containsDirectly`。普通 xref 投影为 `aat:references`；写了 `rel` 的 xref 投影为以谓词命名的边，这里是 `rel:depends-on`。每条 xref 另有一个节点，记下源文本里写的目标 `aat:targetSelector` 和它找到的标题 `aat:targetHeading`。引用写的是标题原文，所以找到的就是那个标题。

写书的人不必自己运行投影。工作区的构建核对引用时读的是这张图，查询工具按 role 列出标题时读的也是这张图。源文本怎样写，决定了它们能从书里读出什么。

`rel` 用哪些谓词，由书自己定。如果菜谱要表明一道菜由另一道菜改良而来，就先在自己的关系谓词声明里加上这个谓词，再在 xref 里使用它：

[source,asciidoc]
----
[.convention, declares=relations]
== 本菜谱的关系谓词

depends-on:: 这道菜以目标为依据，缺了目标就做不成这道菜。
adapted-from:: 这道菜由目标菜改良而来。

[.dish]
== 冰糖红烧肉

由《xref:红烧肉[rel=adapted-from]》改良而来，糖色全用冰糖，收汁更亮。
----

`rel` 里写的每个谓词，都应先写进书的关系谓词声明，写法见《xref:声明本书的约定[]》。

有的标题本身就是一个编号，例如国家标准的标准号。编号由发布机构分配，在全国唯一，读者也按编号查找它。这样的标题宜照原样写下编号，连同其中的空格和连接号，不必另起一个描述性的名字，也不必加 custom ID。引用时，直接写这个编号：

[source,asciidoc]
----
== GB 2760—2014

食品安全国家标准《食品添加剂使用标准》。

[.technique]
== 炒糖色

不自己炒、改用现成的焦糖色时，用量见《xref:GB 2760—2014[]》。
----
