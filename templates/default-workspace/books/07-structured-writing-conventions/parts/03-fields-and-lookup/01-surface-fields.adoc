[#surface-fields]
== 附加字段

named attributes 是源文档表面字段。标题 attrlist 和 xref attribute 可以携带 named attributes；工具链可以保留字段，字段含义由书稿自己的约定负责。

[source,asciidoc]
----
[#example.example, owner=writing-team]
== 示例

示例说明 xref:stable-heading[稳定标题, rel=illustrates, weight=strong]。
----

`.example` 是 role。`owner=writing-team` 是标题附加字段。`weight=strong` 是 xref 边证据上的附加字段。

附加字段不是默认本体。作者添加字段时，也承担字段取值、解释和维护责任。
