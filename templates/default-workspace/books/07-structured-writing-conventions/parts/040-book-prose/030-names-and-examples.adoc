== 名与例

一本书会反复提到同一样东西，也会用例子把规则落到具体处。名字一乱，读者以为说的是两样东西；例子和规则用同一套词，读者分不清哪一句是例子。

[.touchstone]
=== 一样东西一个名字

出处:: 《论语·子路》：“名不正，则言不顺；言不顺，则事不成。” <<lunyu>>
自问:: 同一样东西，全书只用了一个名字吗？

.改前
____
番茄炒蛋要选熟透的番茄。……西红柿切块，鸡蛋打散。
____

.改后
[source,asciidoc]
----
[.dish]
== 番茄炒蛋

别名:: 西红柿炒鸡蛋

番茄炒蛋要选熟透的番茄。……番茄切块，鸡蛋打散。
----

同一样东西换着名字叫，读者会去猜两个名字是不是两样东西。正文应只用一个名字；别的叫法有检索价值时，应写进别名。

[.touchstone]
=== 例子取自书外

出处:: Alfred Tarski，"Der Wahrheitsbegriff in den formalisierten Sprachen"，对象语言与元语言 <<tarski-wahrheitsbegriff>>。
自问:: 例子里的词，会和正在讲的规则混在一起吗？

.改前（一本讲标题写法的书里的例子）
[source,asciidoc]
----
[.concept]
== 常规标题

常规标题提供可引用的阅读单位。
----

.改后
[source,asciidoc]
----
[.dish]
== 红烧肉

红烧肉的红亮先靠糖色。
----

书讲的是标题，例子里的标题又叫“常规标题”，读者读到“常规标题提供可引用的阅读单位”，分不清这是例子的正文，还是书在给标题下定义。例子取自书外的领域，例子里的词就不会被当成规则里的词。
