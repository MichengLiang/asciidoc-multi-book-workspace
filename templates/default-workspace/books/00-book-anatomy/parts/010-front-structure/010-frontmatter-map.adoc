== 前置内容地图

前置内容用于建立读者进入正文之前需要知道的说明、来源和阅读位置。

方括号中的名称是 section style。它作用于紧随其后的 section；当下一行是 include 指令时，style 作用于被 include 文件中的 section 标题。

[cols="1,2", options="header"]
|===
|结构 |职责

|`[colophon]`
|记录版本、出版或来源信息。

|`[dedication]`
|放置献辞。

|`[preface]`
|说明写作目的和阅读方式。

|`[acknowledgments]`
|放置致谢。
|===

书没有摘要。`[abstract]` 是 article 的 section style：摘要概述一篇文章，书的前置内容里没有这一项。在 book 里写 `[abstract]`，Asciidoctor 会把那一节当作普通的一章编号，它后面每一章的编号都跟着多一。一本书覆盖什么、怎样读，写在前言里。
