== 内联结构标记

内联结构标记给正文中的术语、路径和索引入口标出它们的身份，并写出正文对别的章节的引用。它不改变 book 的章节层级，但会提高正文片段的可维护性和可检索性。

[cols="1,2", options="header"]
|===
|写法 |结构作用

|`xref:正文结构地图[]`
|按标题引用同一本书里的一节：标题就是这一节的地址。

|`[#id]`
|custom ID：给标题再加一个地址。只在一节需要被单独引用、又与别的标题同名时才写。

|`indexterm2:[term]`
|把正文中已经出现的词作为可见索引词。

|`indexterm:[term, detail]`
|正文没有出现该词时，补充隐藏索引入口。

|`[.term]#inline role#`
|给术语片段提供语义身份。

|`[.path]` + monospace path
|给路径文本提供语义身份。

|`{series-name}`
|引用共享属性，减少多处重复文本。
|===

语义 inline role 提供结构身份；具体视觉效果取决于输出样式。本书使用 [.term]#inline role# 标记术语片段，使用 [.path]`parts/02-body-structure/` 标记路径片段。
